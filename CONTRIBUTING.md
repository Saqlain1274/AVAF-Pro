Contributing to AVAF Pro

Thank you for your interest in contributing to AVAF Pro!

AVAF Pro is an open-source Academic Web Vulnerability Assessment Framework. We welcome contributions from developers, cybersecurity researchers, students, and security enthusiasts.

How to Contribute

1. Fork the AVAF Pro repository.
2. Clone your fork to your local machine.
3. Create a new branch for your changes.
4. Make your improvements or bug fixes.
5. Test your changes before submitting.
6. Submit a Pull Request explaining your contribution.

Areas Where You Can Contribute

- Vulnerability detection and verification algorithms.
- Browser-based discovery and parameter extraction.
- False-positive reduction.
- Security testing and automated tests.
- Dashboard and user interface improvements.
- Documentation and bug fixes.
- Performance and reliability improvements.

Development Guidelines

- Follow the existing project architecture.
- Keep the GUI separate from vulnerability detection logic.
- Do not introduce fabricated endpoints or vulnerability findings.
- Require genuine, attack-specific evidence before confirming vulnerabilities.
- Include tests for new functionality.
- Avoid unnecessary changes to existing components.

Security and Responsible Testing

- Only test applications you own or have explicit permission to assess.
- Never commit passwords, API keys, private data, or sensitive testing evidence.
- Report security issues responsibly to the project maintainer.

Pull Request Guidelines

Please include:

- A clear description of your changes.
- The problem your contribution addresses.
- Testing performed.
- Any relevant screenshots or evidence.

All contributions are subject to review before being merged.
